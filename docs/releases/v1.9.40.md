# wb2api v1.9.40

修复无前缀模型请求只按“优先国际／国内”选择区域的问题。例如国内目录包含 `kimi-k3.1`、国际目录没有时，请求现在直接进入国内账号池，避免先向国际服试错。

## 按目录归属路由

- 仅出现在国内目录的模型固定走国内池，仅出现在国际目录的模型固定走国际池。
- 两边共有的模型继续按区域优先级选择，并保留跨域回退。目录中归属未知的模型保留原来的优先级行为。
- 归属明确的模型在所属池冷却、禁用或额度不足时，返回该池的实际状态，不再回退到没有该模型的区域。
- 显式 `cn:`／`global:` 前缀继续优先。`global.enabled=false` 的国内锁定行为保持不变。

模型目录、账号冷却和会话绑定使用不同状态。账号冷却结束不会清除目录归属；旧会话绑到错误区域时重新选择账号。后台冷却探活也跳过区域不匹配的模型，避免定时请求错误区域。

分组读取最近成功拉取的目录，不在每次聊天前额外查询上游。启动预热、模型列表和面板查询都会更新分组。临时目录查询失败保留已有分组；以后成功拉取的目录显示另一地区新增支持时，模型自动变为两域共有。

## 验证与升级

通过完整 Go 测试、go vet，以及 server、upstream、scheduler 和 cmd/server 的竞态检查。回归测试覆盖流式和非流式的国内独有／国际独有模型、共有模型优先级、所属池不可用、冷却清除、旧粘性绑定、后台探活跳过，以及目录更新后恢复另一地区候选。

更新程序或镜像并重启即可，无需手动给模型加前缀，也无需调整现有优先级配置。镜像：`ghcr.io/csszyf/wb2api:v1.9.40`。
