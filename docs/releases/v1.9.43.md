# wb2api v1.9.43

同步上游与活跃社区 10 月 18 日～21 日的 6 项不冲突更新，重点修复并发刷新导致 `12153` 掉登录、`14003` 模型繁忙误冷整号，以及 `11158` Pro 专属模型权限识别。

## 本次更新内容

- **同账号 `RefreshToken` 单飞 + 跨进程磁盘恢复（PR #217）**：上游对 `refreshToken` 启用了反重放校验，同一 RT 被并发消费两次会触发 `12153: refresh token is invalid` 并作废整条登录链。现按账号 UID 单飞串行化刷新（不同账号仍并行），并在遇到 12153 时自动检查磁盘凭证是否已被其他进程更新。
- **`14003`「模型繁忙」短窗口模型级停车（PR #234）**：将上游 `429 code=14003`（`displayMsg: "模型繁忙，请换模型或稍后重试"`）识别为模型级瞬时繁忙信号，仅对该 `(账号, 模型)` 停车 60 秒（封顶 3 分钟），不再按账号级软冷却 600 秒，且不误触发付费 SG 回退。
- **`11158` 账号类型模型权限负缓存（PR #221）**：国际版免费账号请求 Pro 专属模型返回 `400 code=11158`（`is not allowed for user type [personal_free_user]`）时，按 `(账号, 模型)` 写入负缓存避让；池内无可用 Pro 账号时直接返回 `400 model_unavailable` 并透传上游原因，不再误报 `503 no_healthy_account`。
- **新增 `cn.chat_base` 配置项（PR #220）**：支持在 `config.json` 中配置 `"cn": {"chat_base": "https://www.workbuddy.cn"}`，解决海外出口下 `copilot.tencent.com` TLS 握手复位导致国内模型无法拉取与调用的问题。
- **支持环境变量代理（PR #223）**：出站 `http.Transport` 默认启用 `http.ProxyFromEnvironment`，自动支持 `HTTP_PROXY` / `HTTPS_PROXY` / `NO_PROXY`。
- **面板脚本 URL 内容指纹（`?v=<sha256>`）**：服务端在返回面板首页时自动为 `app.js` 附加内容哈希参数，升级版本后无需手动 `Ctrl+F5` 即可避免浏览器或反代回放旧脚本。
