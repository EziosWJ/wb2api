# wb2api v1.9.38

修复第三方 WorkBuddy 凭证使用 `realm: "intl"` 时国际服账号无法导入的问题，并在账号池新增单账号与全部账号凭证导出。

## 自动识别凭证区域

- 已知 WorkBuddy 域名优先判定区域：`www.workbuddy.ai` 及其域名家族识别为国际服，CodeBuddy 国内域名识别为国内服。
- 兼容 `intl`、`international`、`overseas`、国际服等标记，统一保存为 `global`；兼容国内服的常见标记。
- 域名支持大小写、尾部斜杠、URL 形式。未知 realm 但域名可识别时正常导入；两者都无法识别时提示补齐信息，不猜测国际服身份。
- 支持 `at` / `rt` 简写。缺少 UID 或令牌仍会给出逐条错误，不用文件名猜测账号区域，不向文件提供的 URL 发送凭证探测。
- 临时关闭 global 路由时，导入仍保留账号实际的国际服身份。

已回归用户提供的形态：`"domain":"www.workbuddy.ai", "realm":"intl"`。

## 导出凭证

- 账号行「导出凭证」：下载 `workbuddy-<uid>.json`。
- 账号池工具栏「导出全部凭证」：下载 `workbuddy-accounts.json`，包含全部池内账号。
- 导出内容采用本程序标准的 auth/account 嵌套结构，可通过「导入 JSON」直接重新导入，保留访问令牌、刷新令牌、到期时间、域名、区域、企业标识、昵称和设备令牌。
- 导出读取当前内存凭证快照，与令牌刷新使用同一把锁，避免将两次刷新的令牌混在一个文件中；不刷新令牌、不改写账号文件。
- 导出接口复用面板鉴权，响应设置 no-store；普通概览和状态接口不返回凭证。下载文件包含登录凭证，请作为备份妥善保存。导出文件不包含每日限额和用量状态，完整迁移仍应保留 data/state.json。

## 验证与升级

通过自动识别、中外账号混合导入、导出再导入、鉴权、敏感响应不缓存、并发刷新一致性测试，以及完整 Go 测试、静态检查和 auth/panel 竞态检查。浏览器用模拟账号验证了下载文件和页面按钮。

升级镜像或程序后重启，再重新导入之前失败的国外 JSON，无需手动把 intl 改成 global。镜像：`ghcr.io/csszyf/wb2api:v1.9.38`。
