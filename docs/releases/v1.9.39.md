# wb2api v1.9.39

修复账号已经导入、面板仍停在自动导入的问题，以及模型目录和测试对话下拉列表长时间加载的问题。合入上游截至 `6b31db6` 的三项更新，保留 Fill First 路由、每日模型 Token 限额、国内与国际视图、凭证导入导出及现有页面布局。

## 导入完成后及时返回

JSON 导入和网页登录在凭证保存、账号载入池后返回成功。注册激活、试用领取、签到和余额查询改为后台队列执行，最多同时处理两个账号。上游收尾请求变慢时，面板不再一直显示导入中；余额随后更新，后台失败写入运行日志。

网页登录增加前后端轮询去重，避免上一次请求尚未结束时再次确认登录。关闭弹窗或切换登录会话后，旧响应不会覆盖新会话。

## 模型列表与测试对话

- 单次上游目录请求和能力补全请求最多等待 4 秒，整条目录查询最多 15 秒。浏览器模型请求最多等待 20 秒，超时后显示错误并允许重新获取。
- 能力补全失败时保留已取到的目录。企业目录失败时尝试 `/v3/config`，成功后同步更新模型能力缓存。
- 测试弹窗立即提供默认模型 `deepseek-v4.1-flash`，可以在目录更新期间测试；目录失败时仍保留默认模型。
- 测试弹窗按所选账号的国内或国际区域查询。快速切换账号、区域或关闭弹窗后，旧响应不会覆盖当前结果。
