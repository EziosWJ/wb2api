# wb2api v1.9.41

修复无前缀 `deepseek-v4.1-flash` 走国际区时，免费额度和 SG 均耗尽后无法继续使用国内同名模型的问题。

## 正确的回退顺序

开启 `pool.deepseek_sg_fallback`、无前缀请求进入国际区时，顺序为：

1. 国际 `deepseek-v4.1-flash` 免费额度。
2. 免费额度全池耗尽后，使用国际 `deepseek-v4.1-flash-sg`。
3. SG 全池模型额度或每日 Token 限额耗尽，或已知余额达到保留积分线后，转国内 `deepseek-v4.1-flash`。

国内 4.1 按积分计费。SG 和国内阶段都要求候选账号健康、并发未满、余额已知且严格高于 `pool.reserve_credits`，同时遵守各自的每日模型 Token 限额。网络故障、WAF、并发占满、缺模型和余额未知不被当作额度耗尽。

原实现为了优先 SG，把请求锁在国际池；SG 阶段结束后没有国内阶段。此版为这条特定回退链补上国内阶段，保留 Kimi 等其他模型的分区路由。即使目录将 4.1 分到国际组，无前缀请求仍可按这条链回退。

每个阶段都有独立的有界轮转额度；最后一个 SG 尝试才确认额度耗尽时，同一请求仍能进入国内阶段，`max_rotate=1` 同样有效。国内成功请求按 `cn:deepseek-v4.1-flash` 记录用量，响应头 `X-WB2API-Actual-Model` 标明实际路由。国际免费额度或 SG 恢复后，新请求重新优先它们，国内会话绑定不会阻止恢复。

显式 `global:deepseek-v4.1-flash` 保持国际免费 → SG，不跨国内；显式 `cn:` 继续走国内。直接请求 SG 不改变模型。此次不增加通用的倍率排序策略。
